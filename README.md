# Fortune in a Pot

One kind, funny fortune for a houseplant, written for the little pothos
on the windowsill: Thursday brings rain for its leaves, and the cat has
sworn, at last, never to taste it again.

`main.py` writes the exact line to `/output/entry.txt`.
